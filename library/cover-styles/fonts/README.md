# Cover fonts

All four are SIL Open Font License 1.1 (licence texts alongside), from github.com/google/fonts `ofl/`, fetched 2026-10-02.

| File | Alias used by cards (`title_font`) | Use |
|---|---|---|
| Limelight-Regular.ttf | `display-deco` | heavy Art Deco display caps |
| PoiretOne-Regular.ttf | `display-thin` | thin geometric Deco caps (magazine mastheads) |
| Cinzel.ttf (variable) | `display-serif` | inscriptional serif caps |
| JosefinSans.ttf (variable) | `small` | strap lines and author line |

A missing file falls back to Georgia, so a cover never fails for want of a font.
